# ChatSplice 0.0.2

GPT Web이 MCP로 프로젝트를 수정하고 실행·검증하는 기능을 확장했습니다. Pi SDK는 명령 실행 tooling, Playwright는 local browser tooling으로 사용하며 별도 모델 API key는 필요하지 않습니다. 지원 대상은 macOS 13 이상, Apple Silicon입니다.

## 변경 사항

- `project.exec`에 개발 shell, Python 환경·프로젝트 설정·설치 후처리, background 서버와 isolated local browser 작업을 추가했습니다.
- 앱 전체 동시 실행 한도를 일반 작업 8개, background 서버 12개, browser 세션 12개, 대기·실행 합계 64개로 확대했습니다.
- 서로 다른 프로젝트에서 같은 `request_id`를 사용했을 때 발생하던 충돌을 수정했습니다.
- Node를 사용하지 않는 shell 명령이 외부 Node 부재 때문에 막히던 문제와, network 허용 shell 설치의 `postinstall`이 건너뛰어지던 문제를 수정했습니다.
- 실행 이력에 shell/browser 작업을 표시하고 await 결과에 screenshot·텍스트·selector·console을 반환합니다.
- 실제 `.app`의 daemon 검증, 소스 archive·file manifest·SHA-256 검증 도구를 제공합니다.
- 영속 Goal·checkpoint·명시적 resume·근거 기반 complete와 readiness/environment 점검을 추가했습니다.
- 모든 owner control API의 capability guard, strict UTF-8·actual-byte manifest 읽기, bounded 실행 hard-link 점검과 신규 hard-link 금지를 보완했습니다.
- 배포는 MIT 소스와 사용자 직접 빌드를 기준으로 전환했습니다. CI의 서명·공증·GitHub Release 게시 작업은 제거했습니다.

## 업그레이드

1. 진행 중인 작업을 마무리하고 미저장 파일을 저장한 뒤 앱을 종료합니다.
2. 새 소스의 locked 의존성을 설치하고 `pnpm verify` 후 `pnpm start`로 실행합니다. App data를 삭제하지 않습니다. 개인 unsigned 앱이 필요하면 `pnpm pack:mac`으로 다시 만듭니다.
3. ChatGPT MCP 앱의 tool catalog를 갱신해 descriptor **0.0.13**을 반영합니다. 도구는 24개, control protocol은 4, execution contract는 `goal-security-2`입니다.
4. Project 지침의 ChatSplice 블록을 갱신하고 새 Project 채팅에서 설치·실행·browser 검증을 요청합니다.
5. Chromium이 없으면 `browser setup` 결과를 확인한 뒤 다시 실행합니다. 프로젝트 언어 runtime은 작업에 맞게 준비합니다.

사용자가 MIT 소스를 받아 본인 Mac에서 빌드합니다. 기본 빌드에는 Apple 서명·공증 자격 증명이 필요하지 않습니다. [직접 빌드 안내](../release-distribution.md), [사용 안내](../developer-workflow.md), [코드 구조](../execution-architecture.md)를 참고하세요.

## 검증 범위

아래는 이전 0.0.2 실행 확장 검증 기록이며, 현재 보안 amendment의 최종 결과는 로컬 진행 기록(`docs/agent-progress.md`)에 별도로 남깁니다.

로컬 `pnpm verify`, 두 real MCP browser workflow, 12개 임시 프로젝트의 병렬 설치·서버·수정·검사·storage 분리·취소를 확인했습니다. 실제 두 Svelte 프로젝트도 MCP로 병렬 typecheck를 실행하고 로그인·페이지 이동·mobile 화면을 점검했습니다. 새 실행기를 사용하는 target-account ChatGPT/Tunnel 호출, 별도 Mac에서의 설치·기존 profile 교체, 현재 source revision의 실제 계정·native 입력·다른 Mac 직접 빌드는 별도로 검증해야 합니다. 서명·자동 앱 업데이트 운영은 현재 범위에서 제외합니다.

ChatGPT 계정의 도구 권한과 사용량 제한은 그대로 적용됩니다. Background 실행은 추적하는 job이며 앱 종료·timeout·취소 시 정리됩니다. 취소는 이미 완료한 파일 저장·설치를 되돌리지 않습니다.
