# Code of Conduct

We want a focused, respectful developer community. Be constructive, assume good intent, and discuss code and product behavior rather than people.

Harassment, discrimination, threats, doxxing, credential sharing, or posting another person's private workspace, ChatGPT content, tokens, or tunnel configuration is not acceptable.

Maintainers may remove content or participation that violates this code. Until a public repository owner and private reporting channel are configured, this file is a release-preparation policy rather than an invitation to publish reports in a public issue.

## 한국어

서로 존중하며 코드와 제품 동작을 중심으로 논의합니다. 괴롭힘·차별·위협·신상 공개, 다른 사람의 workspace·ChatGPT 내용·token·tunnel 설정 공개는 허용되지 않습니다. 공개 저장소의 owner와 비공개 신고 채널이 정해지기 전에는 민감한 내용을 public issue에 올리지 않습니다.
